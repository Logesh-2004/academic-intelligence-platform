# 🎓 Academic Intelligence Platform

An end-to-end **AI-powered Academic Analytics and Student Performance Prediction Platform** built using **Python, Streamlit, Scikit-learn and Ollama (Local SLM)**.

This platform analyzes historical academic data, predicts subject-level risk, projects new student academic performance using background attributes, and generates AI-powered academic advisory reports.

---

## 🚀 Key Features

### 📊 Student Performance Dashboard
- Student-wise performance analytics
- Subject-wise weakness detection
- Internal vs External gap analysis
- Machine Learning based subject risk prediction
- AI Academic Advisor Report using local LLM

---

### 📉 Subject Risk Analytics
- Subject-level pass rate calculation
- Fail rate visualization
- Risk categorization (LOW / MEDIUM / HIGH)
- Teaching focus recommendation support

---

### 🔮 New Admission Academic Projection
- Upload new student admission dataset
- Predict subject-wise internal, external and total marks
- Generate full projected academic dataset
- Batch-level AI summary for academic planning
- Download projected dataset for institutional use

---

### 🧠 AI Academic Advisor (Local LLM)
Powered by **Ollama** (offline inference):

- Student improvement strategy generation
- Faculty intervention suggestions
- Batch teaching optimization advice
- Academic planning support

---

## 🛠 Tech Stack

| Layer | Technology |
------|---------
Frontend | Streamlit
Backend | Python, Pandas
ML Models | Scikit-learn (Random Forest)
Model Storage | Joblib (.pkl)
Local LLM | Ollama (Mistral / Llama3)
Visualization | Streamlit Charts
Platform | Windows / Linux
